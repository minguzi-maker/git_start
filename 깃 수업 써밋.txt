git checkout -b topic   브랜치 새로 만들어서 옮겨가기 => 선언시에는 로컬에만 표기가된 상황(push할때 hub랑연결됨)
git checkout topic   topic브랜치로 이동
git branch  로컬 브랜치 목록만 보여줌
git branch -a  로컬+repository 브랜치를 보여줌

===============================
git fetch origin (브랜치명)  => 모든 브랜치를 다운 받겠다.
git checkout -b topic origin/topic  => 로컬에 topic브랜치만들기(기존) + origion의 topic브랜치 데이터 가져오기
 ==여기까지 로컬에 topic을 추가해서  동기화하는 과정 (master는 변화 없음)

커밋을 하나로 합칠때
rebase , merge할때 squash 사용

git checkout master => git merge --squash topic  => 커밋이 합쳐짐

fast-forward merge =>merge 로그 안남음
=> git merge --no-ff setting_topic => 머지하면서 로그가 남음
<< LOG: Merge branch 'setting_topic' into dev >>



	단계					명령어
처음 각 컴퓨터 세팅				git clone
자기 브랜치 만들기			git checkout -b 브랜치명 + git push -u origin 브랜치명
작업 저장					add → commit → push
다른 컴퓨터 작업 이어보기			git fetch → git checkout 브랜치명
나중에 합치기				master로 이동 후 git merge
